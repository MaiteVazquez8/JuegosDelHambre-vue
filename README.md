# Los juegos del hambre

Una web informativa sobre el universo de "Los Juegos del Hambre".

## Cómo correr el proyecto

1. Instala las dependencias:

```sh
npm install
```

2. Inicia el servidor de desarrollo:

```sh
npm run dev
```

3. Abre la URL que aparezca en la terminal (por lo general, http://localhost:5173).

## Construir para producción

```sh
npm run build
```
